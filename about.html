About Moses

Full-stack software engineer and AI automation consultant. I diagnose operational bottlenecks and build software that scales reliably.

I am a software engineer with over 5 years of hands-on experience building database-driven applications, secure REST APIs, microservices, and responsive web & mobile interfaces. My work spans the entire engineering lifecycle: from database normalization and concurrency locks to frontend component trees, Docker containerization, and production AI pipelines.

My engineering journey began with Java and desktop systems in 2019, where architectural discipline, memory safety, and strict object-oriented modeling were non-negotiable. From there, I expanded into modern web architectures: building high-throughput Spring Boot microservices, high-speed Node.js APIs, and comprehensive Laravel & Vue applications with seamless payment gateway integrations (Stripe, Razorpay).

In recent years, I have supplemented core full-stack engineering with cutting-edge AI automation. I design and deploy autonomous, tool-calling LLM agents (LangGraph, LangChain, LiteLLM) and sub-second voice agents (Vapi, Deepgram) that integrate directly with CRMs, databases, and third-party APIs. I also serve as an AI Model Evaluation Specialist, reviewing model reasoning, identifying hallucinations, and benchmarking model accuracy against rigorous engineering rubrics.

I don't start with a programming language or an arbitrary framework. I start with the constraint: what does the business process require, what does manual intervention currently cost, and how can software eliminate that friction with the lowest operational overhead? Whether building from scratch or refactoring an existing system, my approach is rooted in security, maintainability, and measurable ROI.
