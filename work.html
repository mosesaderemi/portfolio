Microservices2026

Healthcare Management Platform

A distributed microservices ecosystem for hospital operations, real-time patient telemetry, and clinical scheduling.

The Problem

Monolithic healthcare backends frequently face single-point-of-failure risks. When billing or reporting experiences peak load, critical clinical functions like patient triage and appointment scheduling suffer latency or outages.

What I Built

A decoupled microservices platform operating behind a central Spring Cloud Gateway with distributed discovery, central configuration, and JWT role-based authorization:

  • Auth Service: Spring Security 6 token service handling credential rotation and role permissions (Admin, Doctor, Nurse, Patient).
  • Patient & Telemetry Service: Normalized PostgreSQL schema tracking vitals (ECG, SpO2, heart rate) with query optimization.
  • Appointment & Scheduling: Real-time booking with optimistic locking to prevent double bookings across practitioner rosters.
  • Billing Service: Automated invoicing with Stripe webhook reconciliations and JasperReports PDF generation.
  • Client & DevOps: Responsive React + TypeScript dashboard, Docker Compose containerization, and Kubernetes deployment manifests.
My Role

System Architect and Full-Stack Engineer. Designed database schemas, inter-service REST contracts, gateway routing, and the React administrative frontend.

Node.js / Express2026

Institute Management Backend (CIITM)

Full-stack academic operating system with real-time admissions, payment verification, and a Gemini-powered student AI assistant.

The Problem

Educational institutes often run disjointed spreadsheets and standalone billing gateways. Students struggle to check tuition balances and course updates, while administrative staff manually verify payment receipts and answer repetitive inquiries.

What I Built

A high-throughput REST and WebSocket backend integrating financial transactions with generative AI:

  • Admissions & Course Management: Automated student matriculation, dynamic prerequisite checking, and teacher assignments.
  • Secure Multi-Role Auth: JWT and Google OAuth 2.0 with separate scopes for students, faculty, and bursars.
  • Payment Gateway: Razorpay webhook listener for automated invoice issuance and reconciliation.
  • Real-time Broadcasts: Socket.IO channels for instant campus announcements, attendance alerts, and exam timetables.
  • Gemini AI Student Concierge: Embedded conversational assistant answering syllabus queries, tuition balances, and enrollment status.
My Role

Lead Backend Developer. Designed MongoDB document schemas, indexing strategies, payment security, and Gemini AI context prompts.

Autonomous AI & Voice
Python / LangGraph2026

AI Sales & Leads Reactivation Voice Agent

Deterministic tool-calling agent with sub-second telephony outreach, hybrid RAG retrieval, and automated payment generation.

The Problem

Businesses lose thousands in revenue when marketing leads sit unattended for hours. Similarly, hundreds of past customers in CRMs go cold because sales teams lack the bandwidth to conduct manual reactivation phone calls.

What I Built

An end-to-end autonomous agent workflow combining natural conversational speech with programmatic tool execution:

  • State Machine with LangGraph: Bounded decision graphs preventing hallucinated loops, managing conversation states with memory checkpointing.
  • Tool-Calling Architecture: Executes CRM lookups, calculates quote discounts, checks calendar availability, and creates Stripe payment links in real-time.
  • Sub-second Voice Pipeline: Integrates Vapi and Deepgram speech-to-text / text-to-speech for low-latency phone calls.
  • CRM Two-Way Sync: Analyzes post-call transcripts, extracts lead qualification scores (0-100), and records outcomes in Airtable and HubSpot.
My Role

AI Architect & Developer. Built the prompt engineering pipeline, FastAPI webhooks, tool execution registry, and telephonic voice integration.

Python LangGraph LiteLLM FastAPI Vapi & Deepgram Chroma DB Stripe API
